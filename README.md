# Driver Drowsiness Detection System

A real-time driver monitoring system that detects signs of drowsiness from a webcam feed and alerts the driver.

## Features
- Eye Aspect Ratio (EAR) detection to spot closed or drooping eyes
- Mouth Aspect Ratio (MAR) detection to spot yawning
- Mobile phone detection
- Audio and visual alerts
- Login and admin modules with an SQLite database

## Tech Stack
Python, OpenCV, MediaPipe, TensorFlow Lite, Tkinter, SQLite

## How to Run
1. Install Python 3 and the required libraries (OpenCV, MediaPipe, NumPy, TensorFlow Lite)
2. Connect a webcam
3. Run: `python mini_project.py`

## Note
The database file is not included for privacy. It is created when the app runs for the first time.
